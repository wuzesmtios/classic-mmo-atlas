# 硬核网游攻略库 (Game Mechanics Wiki)

> 专注精品网络游戏的深度硬核教程。分享精确到数值的职业机制解析、高效跑图路线、BOSS 行动轴拆解与独家资源规划策略。用数据驱动游戏，告别盲目摸索。

## 📖 关于本项目

本项目是部署于 GitHub Pages 的静态攻略站点，旨在为玩家提供最纯粹的数值拆解和机制分析。同时，底层目录与链接架构专为搜索引擎优化（SEO）设计，确保高质量内容能够被快速抓取和收录，适合作为流量沉淀的基础设施。

## ✨ 核心架构与特性

- **硬核数据驱动**：拒绝模糊描述，所有进阶攻略均以实际游戏数值、帧数分析和行动轴拆解为基础。
- **极简数字路由**：为避免中文 URL 转码和超长拼音带来的抓取错误与权重流失，**内容页路由严格使用纯数字 ID**（例如 `/guides/10255.html`），不使用拼音别名。
- **多维度词汇聚合**：底层数据结构支持多对一映射。当一篇攻略覆盖多个搜索词变体（例如不同玩家对同一副本的多种称呼）时，系统会将这些变体并发映射到同一个核心 ID 路由上，实现权重的绝对集中。
